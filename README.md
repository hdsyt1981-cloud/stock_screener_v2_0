# 전체종목 분석 · Stock Glass v2.0

GitHub + Streamlit 배포용 전체시장 스크리너입니다. 기존 `stock_screener_v2_0.py`의 종목별 모델·홀드아웃/WFO 평가·분류·순위 계산을 호출하며, 이 프로젝트에서는 모바일/PC용 글라스모피즘 화면과 결과표/Excel 다운로드 UI를 제공합니다.

## 파일 구성
- `app.py`: Streamlit 화면과 실행 흐름
- `stock_screener_v2_0.py`: 전체종목 분석 엔진(원본 스크리닝 코드)
- `requirements.txt`: 설치 라이브러리
- `.streamlit/config.toml`: 짙은 테마 및 글씨 대비 설정

## GitHub / Streamlit 배포
1. 이 폴더 안의 파일을 GitHub 저장소 루트에 업로드합니다. `.streamlit/config.toml`도 포함해야 합니다.
2. Streamlit Community Cloud에서 저장소를 연결합니다.
3. Main file path는 `app.py`로 설정합니다.
4. 앱을 실행하고 먼저 30개 안팎의 시험 실행으로 데이터 연결을 확인합니다.
5. 문제가 없으면 `전체 구성종목 분석`을 선택해 KOSPI 또는 S&P 500 전체 목록을 분석합니다.

## 분석 기준과 주의사항
- 기본 목표 상승률: +15%; 최대 보유기간: 20거래일
- 기본 수수료: 0.05%/편도; 슬리피지: 0.15%/편도
- 원본 스크리너의 분류 기준과 종목별 계산을 별도 UI에서 재구현하지 않습니다.
- 전체 분석은 종목별 WFO/홀드아웃 평가로 시간이 오래 걸릴 수 있습니다. 실행 중 서버가 재시작될 수 있으므로 첫 실행은 일부 종목으로 확인하세요.
- 종목목록은 FinanceDataReader의 현재 구성종목을 사용합니다. 과거 상장폐지 종목 및 과거 구성종목 변동이 완전히 복원되지 않는 생존편향 가능성이 있습니다.
- 미국 종목 수익률은 엔진과 동일하게 현지 통화 기준이며 환율 손익은 별도 반영하지 않습니다.
- 모델 점수는 보정된 성공확률이 아니며, 과거 검증 결과가 미래 수익을 보장하지 않습니다.
